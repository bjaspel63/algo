# Algorithm Quest — Clean Firebase Version

## Important
Run this through a web server (Firebase Hosting, VS Code Live Server, etc.). Do not double-click `index.html` as a `file://` URL.

## Firebase
This package uses the supplied Firebase Web App configuration for `algo-9c999` and Realtime Database.

Enable **Realtime Database** in Firebase Console. For initial classroom testing, rules can temporarily be:

```json
{
  "rules": {
    ".read": true,
    ".write": true
  }
}
```

Use authenticated/restricted rules for a public deployment.
